# Áurea — React Animated v2

## Ejecutar
npm install
npm run dev

## Incluye
- Motion para reveal, stagger, hover y transiciones.
- Lenis para scroll suave.
- Texto dividido con blur/reveal.
- Contadores animados.
- Zoom cinematográfico del hero.
- Botones magnéticos.
- Cursor contextual en escritorio.
- Revelado de imágenes con clip-path.
- Timeline animada al entrar en pantalla.
- Diseño responsive.
